# 维护「大兴安岭南线追秋」路书

本仓库是一份已归档的历史路书（2026.09.25—10.03 的计划，不证明旅行实际完成），发布为 `https://real-jacket.github.io/trip-khingan/`。保留暖纸色、深绿的摄影杂志风；访客页面只呈现旅行所需信息，研究和技术说明放在 `docs/` 或 `work/`。

## 开始前

先读仓库的 `AGENTS.md`、`README.md` 与 [维护指南](../../docs/maintain.md)。本技能的维护副本位于 `skills/travel-journal/`，解析 `SKILL.md` 的真实文件路径后，上两级是仓库根；本地技能入口可能是指向此目录的符号链接。

检查当前 Git 状态和实际源文件，保留无关改动。路书内容以 `site/index.html` 为准，不凭记忆补日期、酒店或费用。

## 执行分工

协调者（主模型）负责需求与路线分析、计划、设计决策和独立最终验收；执行委派给用户指定的 Sonnet 5.5 子代理，推理强度 high，分派时写明目标文件、预期行为与验收证据。执行者自报不能替代协调者验收，发布遵守当前授权。细则见 [维护指南的执行分工](../../docs/maintain.md#执行分工)。

## 执行

1. 弄清本次要改什么：某个机位或参考图、某天行程、住宿、清单、地图范围或路线。缺少会改变结论的事实时只询问必要信息，其他可独立工作继续推进。
2. 需要更新机位或资料时，使用 agent-reach 技能（先跑 `agent-reach doctor --json`），按 [调研手册](references/research.md) 执行；原始资料放 `work/research/`，台账放 `work/ledger.md`，并与文旅、景区、气象和运营方资料交叉核对。无法完整读取时保留具体边界，不伪造已观看或精确机位。
3. 修改 `site/index.html` 及其本地资产，保留照片署名、全部交互、存储容错和桌面、手机都可见的“回旅行首页”链接；不要复制私有地图配置、平台临时签名或整个研究目录。改动 `site/trip.json` 时保持清单有效。
4. 地图：编辑 `map.json`，用 `pnpm map:build --routes|--extract [--dry-run]|--landcover|--validate` 重建 `site/map/`，合计不超过 40 MB；重建的二进制会永久留在 Git 历史里，别反复重建。
5. 执行 `pnpm check`；自己运行 `pnpm preview`，用真实浏览器核对 1280px 桌面与 390px 手机：地图渲染、控制台无错误、无横向溢出、返回首页链接、本次改动涉及的交互。测试通过不能替代运行和视觉证据。
6. 仅当用户本次明确要求推送或上线时：按授权提交并推送，等待该 commit 的 Pages 工作流成功，打开公网站点与 `trip.json` 验证。仅要求本地修改时，交付该范围的实际结果。

## 内容标准

- 拍摄参考选择能学习构图的作品，明确地点、地面/平台/岸边/航拍视角和可进入方式。原作拍摄日、发布日期、原 EXIF 与本路书参数建议分开；成片后期、叶色与雾的未知情况标清。署名和原帖不是自动转载授权。
- 地图用共用 `TripMap` 模块和 `pnpm map:build` 生成的数据：土地覆盖着色加山体阴影、分级路网（含编号）与行政境界地名、按天的真实道路路线和中文图例；国界与争议线不画。地图下方保留按段的“用高德查看路线”清单（起点 → 途经 → 终点，GCJ-02，驾车模式）。停车入口与景区参考中心不能混用。
- 日程给交通、吃饭、睡眠和停拍留时间；住宿逐晚匹配下一处机位；历史设施/消费与当前可用性分开。
- 本路书是 `archived` 历史路书，不因日期已过声称旅行实际完成。

## 交付

说明更新了什么、可用入口、检查证据，以及现场信息、网络依赖或图像许可的具体未核实项。本流程不授予空白发布权限，也不新增后台、账号或数据库。
